Citizen services

Everything needed to report an infrastructure problem

The citizen experience is designed to be simple, mobile-friendly and accessible while still collecting enough evidence for authority staff to investigate and prioritise repairs.

Photo evidence

Upload a clear image of a pothole, damaged road surface, broken streetlight, pavement defect or drainage problem.

Precise location

Add the road name, postcode, landmark or GPS coordinates to help the correct maintenance team find the issue quickly.

Report tracking

Use the generated report ID to view the current status from submission through review, assignment and final resolution.

Email updates

Receive automatic notifications when a report is created, assigned, updated or marked as resolved by authority staff.

Serverless workflow

From citizen report to completed road repair

The platform uses an event-driven AWS architecture to process reports, store photographs and metadata, notify staff and monitor the application.

1

Citizen submits

The user enters issue details, location and chooses a photograph.

2

Photo uploads

The browser uploads the image directly to the protected S3 image bucket.

3

Report is stored

Lambda validates the request and stores report metadata in DynamoDB.

4

Authority manages

Staff search, assign and update reports using the authority dashboard.

5

Citizen is notified

SNS sends progress updates until the infrastructure issue is resolved.

Authority workspace

Professional dashboard for road-maintenance teams

A central workspace for council or highway-authority staff to review evidence, filter reports, assign teams, update statuses and maintain accountability.
